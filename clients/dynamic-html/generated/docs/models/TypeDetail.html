TypeDetail

    The identifier for this resource.
  • name : String
    The name for this resource.
  • damageUnderscorerelations : TypeRelationships
    A detail of how effective this type is toward others and vice versa.
  • pastUnderscoredamageUnderscorerelations : List
    A list of details of how effective this type was toward others and vice versa in previous generations
  • gameUnderscoreindices : List
    A list of game indices relevent to this item by generation.
  • generation : GenerationSummary
    The generation this type was introduced in.
  • moveUnderscoredamageUnderscoreclass : MoveDamageClassSummary
    The class of damage inflicted by this type.
  • names : List
    The name of this resource listed in different languages.
  • pokemon : List
    A list of details of Pokémon that have this type.
  • moves : List
    A list of moves that have this type.
  • sprites : Map
    Type icons grouped by generation and game, with name_icon and symbol_icon URLs. Unavailable icons are null.
