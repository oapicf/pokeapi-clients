MoveMeta

  • ailment : MoveMetaAilmentSummary
    The status ailment this move inflicts on its target.
  • category : MoveMetaCategorySummary
    The category of move this move falls under, e.g. damage or ailment.
  • minUnderscorehits : Integer
    The minimum number of times this move hits. Null if it always only hits once.
  • maxUnderscorehits : Integer
    The maximum number of times this move hits. Null if it always only hits once.
  • minUnderscoreturns : Integer
    The minimum number of turns this move continues to take effect. Null if it always only lasts one turn.
  • maxUnderscoreturns : Integer
    The maximum number of turns this move continues to take effect. Null if it always only lasts one turn.
  • drain : Integer
    HP drain (if positive) or Recoil damage (if negative), in percent of damage done.
  • healing : Integer
    The amount of hp gained by the attacking Pokemon, in percent of it's maximum HP.
  • critUnderscorerate : Integer
    Critical hit rate bonus.
  • ailmentUnderscorechance : Integer
    The likelihood this attack will cause an ailment.
  • flinchUnderscorechance : Integer
    The likelihood this attack will cause the target Pokémon to flinch.
  • statUnderscorechance : Integer
    The likelihood this attack will cause a stat change in the target Pokémon.
